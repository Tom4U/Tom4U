## Trainings & Teaching Approach

I offer professional trainings across a wide range of topics, including:

- **Modern Web Development** - Angular, React, Vue.js, Svelte, TypeScript, Node.js
- **.NET & C#** - C#, ASP.NET Core, WPF
- **Cloud & Azure** - Azure services, Bicep / IaC, certification paths
- **DevOps & Tooling** - GitHub Actions, Azure DevOps, CI/CD pipelines, Git, PowerShell
- **Software Craftsmanship** - Clean Code, SOLID, Test-Driven Development (TDD)
- **Security** - Web application security, OWASP, ethical hacking
- **Power Platform** - Power Apps, Power Automate, certification paths
- **AI-native Development** - AI-assisted workflows, LLMs, RAG, agent systems, prompt engineering, AI coding assistants (GitHub Copilot, Claude, Gemini)

Each training includes structured theoretical introduction, live coding sessions, hands-on exercises, and complete working solutions.

My goal is long-term understanding - not just short-term results:

- Clear separation between theory and practice
- Real-world example projects throughout
- Fully reproducible environments
- Strong focus on practical application
